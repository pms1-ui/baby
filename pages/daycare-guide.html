어린이집 입소대기 완벽 가이드

제도 이해부터 실전 전략까지, 어린이집 입소대기의 모든 것을 정리했습니다.

🌼 시작 전에 꼭 알아야 할 것

⚠️ "먼저 넣은 사람이 먼저 간다"는 오해입니다!

입소는 신청 순서가 아니라 우선순위 점수로 결정됩니다.

• 대기번호는 '확정 순번'이 아닙니다

• 새 대기자가 추가되면 밀릴 수 있고, 앞 순번 취소 시 당겨질 수 있음

• 신청은 출생신고 후부터 (주민등록번호 필요)

• 태아 명의로는 대기 불가

📱 신청 방법

유보통합포털 (enter.childinfo.go.kr) — 신규 신청

아이사랑 (childcare.go.kr) — 순번 관리, 보육료 결제

서울 소재 어린이집 → 서울시 보육포털 (iseoul.seoul.go.kr)

기준은 "사는 곳"이 아니라 어린이집 소재지! 3곳 한도는 두 시스템 합산.

신청 절차

1. 회원가입·로그인 (공동인증서)

2. 아동등록 (출생신고 완료 아이)

3. 어린이집 검색 (주소지 제한 없음)

4. 입소대기 신청 (미재원 최대 3곳 / 재원 중 최대 2곳)

5. 결원 발생 시 어린이집에서 연락

🎯 3곳, 어디에 넣을까

1️⃣ 국공립 인기원 — 다음 해 3월 신학기 목표

2️⃣ 중간 경쟁률 원 — 현실적 대안

3️⃣ 가정·민간 — 지금 당장 자리 날 가능성

❌ 인기원만 3곳 → 대기 200번대 3개 생길 수 있음!

유형별 특징

• 국공립: 경쟁률 매우 높음, 중간입소 어려움, 규모 큼

• 가정: 경쟁률 낮은 편, 중간입소 비교적 쉬움, 영아 밀착보육 강점

• 민간: 경쟁률 보통, 시설마다 편차 큼

⚖️ 우선순위 점수

• 1순위: 항목당 100점

• 1순위 + 맞벌이: 200점

• 1순위 + 3자녀 이상: 200점

• 2순위: 항목당 50점

• 3순위 (일반): 0점

⚠️ 2순위는 아무리 합산해도 1순위를 이길 수 없습니다!

동점일 때만 입소대기 신청 순서로 결정

증빙 서류 (입소일 7일 전까지)

• 맞벌이: 재직증명서, 건강보험 자격득실확인서

• 다자녀: 주민등록등본, 가족관계증명서

• 해당 시: 한부모가족 증명서, 수급자 증명서

📊 2026년 0세반 변경사항

교사 대 아동 비율: 1:3 → 1:2로 개선

✅ 좋은 점: 돌봄이 훨씬 세심해짐

⚠️ 알아둘 점: 한 반 인원이 줄어 0세반 자리가 더 귀해질 수 있음

🔍 앱 순번만 믿지 말고 직접 전화하세요

아이사랑 앱 대기번호와 실제 입소 가능 순번은 다를 수 있습니다.

• 앞 순번이 이미 다른 어린이집에 입소

• 입소를 미루거나 보류 중인 가정 존재

• 예: 앱에서 6번 → 실제 입소 의사 있는 대기 2명

🌼 전화 멘트

"아이사랑에는 대기 ○번으로 확인되는데요.
실제로 입소 가능성 있는 대기 인원은 어느 정도인지 알 수 있을까요?
혹시 제 앞 순번 중에 보류 상태인 분들이 있는지도 알 수 있을까요?"

📅 입소희망월, 원장님께 직접 여쭤보기

어린이집마다 반 구성과 결원 시기가 다릅니다.

임의로 바꾸기 전에 어떤 달이 유리한지 직접 물어보세요!

🌼 전화 멘트

"현재는 ○월 입소희망으로 신청해 두었는데요.
현재 반 구성이나 대기 상황을 봤을 때, 다른 희망월로 설정하는 것이 입소 가능성에 더 유리할까요?"

🌟 원장님께 기억되는 보호자 되기

전화한다고 순번이 앞으로 가지는 않지만, 결원이 생겼을 때 바로 입소 가능한 보호자로 기억되는 것이 중요합니다.

✔️ 입소가 꼭 필요한 이유를 간단히 말씀드리기

✔️ 아이 이름과 현재 희망월 알려드리기

✔️ "결원 생기면 바로 입소 가능합니다" 전달

✔️ "조금 일러도 가능합니다" 의사 전달

✔️ 순번 당겨달라 요구 ❌ → 예의 있게 간절함 표현

🌼 전화 멘트 (대면 추천)

"저희 아이는 ○○이고, 제가 ○월에 복직 예정이라 중간입소가 꼭 필요한 상황입니다.
혹시 결원이 생기면 조금 이르더라도 바로 입소할 수 있습니다.
가능하시다면 저희 아이도 한 번만 꼭 기억해 주시면 정말 감사하겠습니다."

⏰ 피해야 할 시간: 오전 8~9시 등원 / 오후 4~6시 하원 / 낮잠 시간

🕐 일찍 연락 오면 자리 확보를 고민하세요

원하는 시기에 정확히 자리가 나는 경우가 많지 않습니다.

이번 기회를 포기하면 다음 결원까지 훨씬 오래 기다릴 수 있어요!

• 0세반은 정원 적고, 결원 시점 일정하지 않음

• 초기에는 짧은 시간부터 적응기간 운영 가능

• 입소 시 부모급여→보육료 지원으로 전환됨

🚫 신학기 지나도 대기 취소하지 마세요

3월 이후에도 중간입소 자리가 생길 수 있습니다:

• 아이가 적응 못해 퇴소

• 보호자 육아휴직 연장

• 이사, 직장 변동

• 앞 순번 보호자들 상황 변화

🌼 전화 멘트

"혹시 0세반은 신학기 이후에도 중간에 결원이 생기는 경우가 있을까요?
대기를 계속 유지하고 싶은데, 결원이 생기면 연락받을 수 있을까요?"

⚠️ 입소 후 7일 — 가장 중요한 규칙

어린이집에 입소 처리되면, 다른 어린이집의 입소대기 건은 7일 이내에 '연장'하지 않으면 자동 삭제됩니다!

가정 → 국공립 환승 전략

1️⃣ 가정어린이집 먼저 입소 (돌봄 공백 해결)

2️⃣ 입소 후 7일 이내 기존 대기 '연장' 클릭 ← 핵심!

3️⃣ 재원 중 최대 2곳 유지

4️⃣ 다음 해 3월 신학기에 국공립 이동

이미 삭제됐더라도 3개월 이내라면 복구 가능 (아이사랑 → 취소현황 → 대기복구)

📅 준비 일정 타임라인

• 출생신고 직후: 입소대기 신청 (3곳 다 채우기)

• 입소 희망 6개월 전: 순번 확인, 어린이집 상담

• 입소 희망 3개월 전: 중간입소 가능 여부 확인

• 입소일 7일 전: 증빙 서류 준비 완료

• 입소 후 7일 이내: 기존 대기 연장 신청 ⚠️

• 다음 해 2월: 신학기 입소 확정 여부 확인

🧸 대기 중 활용 서비스

• 시간제보육: 시간 단위 이용, 정부 지원

• 아이돌봄서비스: 가정으로 돌보미 방문

• 육아종합지원센터: 지역별 프로그램, 장난감 대여

⭐ 핵심 정리

✔️ 대기번호는 계속 바뀔 수 있습니다

✔️ 앱 순번만 보고 포기하지 말고 직접 전화하세요

✔️ 국공립뿐 아니라 민간·가정도 함께 알아보세요

✔️ 원장님께 입소 의사를 확실히 전달하세요

✔️ 희망월은 어린이집에 먼저 문의 후 변경하세요

✔️ 조금 일찍 연락 와도 자리 확보를 고민하세요

✔️ 3월 지나도 대기를 취소하지 마세요

✔️ 입소 후 7일 이내 기존 대기 연장 절대 잊지 마세요
